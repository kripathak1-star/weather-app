# 3D Gyaan — video factory
Hindi 3D news-explainer videos for the 3D Gyaan YouTube channel.
- `RUNBOOK.md`: nightly procedure (topics, plan, render, hand to owner)
- `engine/engine.html`: three.js engine driven by a plan JSON
- `scripts/make_video.sh plans/x.json out/x`: plan to finished video + thumbnail
Run `./setup.sh` first.
